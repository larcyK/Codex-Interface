# Codex Interface モバイルUI/UXフロー（MVP）

最終更新: 2026-05-14

## 1. 画面一覧
1. 起動画面
2. 接続先選択（検出一覧 + 手動追加）
3. PIN認証
4. ダッシュボード（状態表示）
5. 操作画面（コマンド実行）
6. ログ画面
7. 設定画面

## 2. 主要ユーザーフロー

### 2.1 初回接続
1. 起動
2. mDNSで候補取得
3. 接続先選択 or 手動IP入力
4. 証明書フィンガープリント確認
5. PIN入力
6. ダッシュボード遷移

### 2.2 コマンド実行
1. 操作画面でコマンド選択
2. 引数入力
3. 実行
4. 実行中表示（stdout/stderrストリーム）
5. 完了通知

### 2.3 ネットワーク切断
1. WS切断検知
2. バナー表示「再接続中」
3. 自動再接続
4. 復帰時に未同期ログ補完

## 3. UI原則
- 接続状態を常時ヘッダ表示
- 危険操作（停止/強制終了）は二段階確認
- 失敗時は再試行ボタンを明示
- ログは検索とフィルタを用意

## 4. MVPワイヤーフレーム（テキスト）
- 接続先一覧: ホスト名 / IP / 最終応答 / 接続ボタン
- ダッシュボード: codex状態, 現在セッション, 最近ログ3件
- 操作画面: コマンド選択, 引数フォーム, 実行ボタン, ストリーム出力
