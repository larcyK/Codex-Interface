# Codex Interface LAN実機テスト計画（MVP）

最終更新: 2026-05-14

## 1. テスト目的
- 同一LANでの接続・認証・操作・ログ閲覧の成立確認
- 切断復帰・性能・失敗系の確認

## 2. 検証環境
- PC: macOS（Gateway + Codex）
- 端末: iPhone 1台, Android 1台
- ネットワーク: 同一Wi-Fi（2.4GHz/5GHz両方）

## 3. 主要テストケース

### 3.1 接続
1. mDNSで検出できる
2. 手動IPで接続できる
3. 接続失敗時に明確なエラーが出る

### 3.2 認証
1. 正しいPINでログイン成功
2. 誤PINで失敗し、一定回数でレート制限
3. トークン期限切れでrefreshが動作

### 3.3 操作
1. コマンド実行で`accepted`受信
2. stdout/stderrがストリーム表示される
3. cancelで停止できる

### 3.4 ログ
1. 最新ログ取得
2. cursorページネーション
3. 再接続後の欠損補完

### 3.5 耐障害
1. Wi-Fi OFF/ONで再接続
2. Gateway再起動後に復帰
3. Codex停止時にdegraded表示

## 4. 合格基準
- 主要ケース95%以上成功
- 致命的障害0件
- 再接続成功率90%以上

## 5. 計測指標
- 初回接続時間
- コマンド受理までの時間
- WS再接続時間
- APIエラー率
