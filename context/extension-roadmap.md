# Codex Interface 拡張ロードマップ（MVP後）

最終更新: 2026-05-14

## 1. 目的
MVPで成立したLAN操作基盤を、外部アクセス・権限管理・運用性の方向に拡張する。

## 2. フェーズ

### Phase A: セキュリティ強化
- デバイスごとの証明書ピンニング
- 監査ログの署名・改ざん検知
- セッション異常検知（IP/UA変化）

### Phase B: 認可強化
- ロール追加（viewer/operator/admin）
- コマンド単位の権限制御
- 操作承認フロー（高リスク操作）

### Phase C: リモートアクセス
- Tailscale/WireGuard連携
- クラウド中継（オプション）
- NAT配下での到達性改善

### Phase D: 運用性
- 通知連携（失敗時Push）
- メトリクス可視化（Prometheus/Grafana）
- バックアップ・リストア

## 3. 優先度
1. セキュリティ強化
2. 認可強化
3. リモートアクセス
4. 運用性改善

## 4. 成果指標
- 不正アクセス試行の検知率
- 権限逸脱操作の防止率
- リモート接続成功率
- MTTR（障害復旧時間）短縮
